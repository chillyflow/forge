The bug in the `Contains` function is that the loop condition `i < len(xs)-1` 
excludes the last element from being checked. This means when searching for the
last element in a slice, it will never be found even if it exists.



The fix is to change the loop condition to `i < len(xs)` so that all elements 
including the last one are checked.

                }
